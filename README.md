# 동네 평생학습 MCP (파일럿)

우리 동네 평생학습 강좌를 **실시간으로** 찾아 주는 MCP 서버입니다. (v0.5)

| 기관 | 수집 방식 | 상태 |
|---|---|---|
| 경주시 평생학습가족관 | 강좌 목록 화면 실시간 조회 | **동작 중** — 강좌 325건 · 기관 명부 82곳 |
| 대구평생학습플랫폼 | 공공데이터포털 공식 오픈API | 인증키 설정 후 동작 |

**대구 설정을 안 해도 경주만으로 정상 동작합니다.** 먼저 돌려 보고 나중에 붙이셔도 됩니다.

### 실측으로 확인된 것 (2026-07)

- 경주시 평생학습가족관 강좌 **325건** (그중 접수 가능 101건, 전 강좌 유료)
- 관내 평생교육기관 **82곳**이 명부에 등록. 유형별로는 평생학습사랑방·학습포석정 39%, 주민자치센터 27%
- 다만 **기관별 개설 강좌는 포털에 연계돼 있지 않습니다.** 82곳 중 강좌 정보가 올라온 곳은 가족관 한 곳뿐입니다. 그래서 기관 명부는 별도 툴(`find_institutions`)로 제공하고, 강좌 수집 대상에서는 제외했습니다
- 특성화 프로그램 메뉴는 현재 등록된 프로그램이 없습니다 (사이트가 직접 그렇게 표시)

## 1. 설치

### 1-1. Python 확인

명령 프롬프트(cmd)를 열고,

```
python --version
```

`Python 3.10` 이상이면 됩니다. 없거나 낮으면 [python.org](https://www.python.org/downloads/)에서 설치하세요.
설치할 때 **"Add Python to PATH"** 체크를 꼭 하십시오.

### 1-2. 필요한 패키지 설치

이 폴더에서,

```
pip install -r requirements.txt
```

### 1-3. 잘 되는지 먼저 확인

```
python selftest.py
```

이게 이 파일럿에서 **가장 중요한 단계**입니다. 무엇이 되고 무엇이 안 되는지 항목별로 나옵니다.

```
[1] 파서 로직 점검      → 코드 자체가 정상인지
[4] 경주 실시간 접속    → 실제로 강좌를 가져오는지
[5] 페이지 이동 탐지    → 전체를 가져올 수 있는지
[6] 대구 설정 확인      → API 키가 붙었는지
```

`결과: 정상` 이 나오면 다음 단계로 갑니다.

## 2. Claude 데스크톱에 연결

### 2-1. 설정 파일 열기

Windows 탐색기 주소창에 아래를 붙여넣고 Enter:

```
%APPDATA%\Claude
```

`claude_desktop_config.json` 파일을 메모장으로 엽니다. 없으면 새로 만드세요.

### 2-2. 내용 붙여넣기

```json
{
  "mcpServers": {
    "dongne-pyeongsaeng": {
      "command": "python",
      "args": ["C:\\\\여기에\\\\실제경로\\\\dongne_pyeongsaeng\\\\server.py"]
    }
  }
}
```

**경로 주의사항 두 가지**

- 역슬래시는 `\\` 두 개씩 써야 합니다
- 실제 `server.py` 위치로 바꾸세요. 파일 탐색기에서 server.py를 Shift+우클릭 → "경로로 복사"하면 정확한 경로가 나옵니다

이미 다른 MCP를 쓰고 계시면 `mcpServers` 안에 `"dongne-pyeongsaeng": { ... }` 항목만 추가하면 됩니다.

### 2-3. Claude 데스크톱 완전 종료 후 재시작

작업표시줄 아이콘에서 종료까지 해야 반영됩니다.

## 4. 툴 4개

### `find_courses` — 강좌 찾기

| 조건 | 설명 |
|---|---|
| `region` | 전체 / 경주 / 대구 |
| `keyword` | 강좌명·기관명·주제 검색어 |
| `weekday` | "월", "화수", "토일" 처럼 자유 입력 |
| `time_slot` | 오전(6-12) / 오후(12-18) / 저녁(18-23) / 주말 |
| `free_only` | 무료만 (수강료 미확인 건도 포함) |
| `open_only` | 접수 마감 안 지난 것만 (기본 켜짐) |
| `has_seats` | 정원이 남은 것만 |

결과는 **마감 임박순**으로 정렬됩니다.

### `get_course_detail` — 강좌 하나 자세히

`find_courses` 결과에 표시된 `id`를 넣으면 정원·접수방법·문의처까지 보여 줍니다.

### `find_institutions` — 평생교육기관 찾기

강좌가 아니라 **"어디서 배울 수 있나"**에 답합니다. 경주 관내 82곳을 유형별로 묶어 보여 줍니다.

| 조건 | 설명 |
|---|---|
| `keyword` | 기관명 검색어 (도서관, 안강, 공방 등) |
| `category` | 평생학습사랑방·학습포석정 / 주민자치센터 / 도서관 / 대학 평생교육원 / 복지·가족 시설 / 청소년 시설 / 문화 시설 / 지자체 평생학습관 / 민간 학원 / 민간 평생교육원 |

기관별 개설 강좌는 포털에 없으므로, 강좌 문의는 각 기관에 직접 하셔야 한다는 안내를 응답에 함께 붙입니다.

### `check_sources` — 소스 진단

지금 어느 기관이 살아 있는지, 몇 건이 수집되는지, 대구 설정이 됐는지 알려 줍니다.
**결과가 이상할 때 제일 먼저 이걸 돌려 보세요.**

## 5. 대구 붙이기 (나중에 하셔도 됩니다)

### 5-1. 공공데이터포털 활용신청

1. https://www.data.go.kr/data/15061491/openapi.do 접속
2. 회원가입 후 **활용신청** (무료, 대개 즉시 승인)
3. 마이페이지 → 오픈API → 개발계정 상세보기에서 두 가지를 복사
   - **일반 인증키 (Decoding)**
   - **요청 주소** (엔드포인트 URL)

> 요청 주소를 코드에 박아 두지 않은 이유: 데이터셋이 개편되면 주소가 바뀝니다.
> 그때 코드를 고치는 대신 설정만 바꾸면 되도록 했습니다.

### 5-2. 설정 파일에 추가

```json
{
  "mcpServers": {
    "dongne-pyeongsaeng": {
      "command": "python",
      "args": ["C:\\\\여기에\\\\실제경로\\\\dongne_pyeongsaeng\\\\server.py"],
      "env": {
        "DAEGU_API_KEY": "여기에_일반인증키_Decoding",
        "DAEGU_API_URL": "여기에_요청주소"
      }
    }
  }
}
```

Claude 재시작 후 `데이터 소스 점검해줘` 로 확인하세요.

## 6. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| **파일을 바꿨는데 결과가 그대로** | `selftest.py` 맨 위 `sources.py: 구버전 의심` 확인. 브라우저가 `sources (1).py`로 저장했을 수 있음 |
| Claude에 툴이 안 보임 | 설정 파일 경로의 `\\` 개수, Claude 완전 재시작 여부 |
| "빈 응답을 보냈습니다" | 기관 사이트 점검 중이거나 차단. 잠시 후 재시도 |
| "강좌 표를 못 찾았습니다" | 사이트 구조 변경. `python selftest.py --dump` 로 원본 저장 후 확인 |
| 10건만 나옴 | 페이지 이동 파라미터 미탐지. 동작에는 문제 없음 |
| 대구가 "미설정" | 5장 참고 |
| 대구 "인증키 확인" 오류 | Encoding 키를 넣었을 가능성. **Decoding** 키를 쓰세요 |

## 7. 이 파일럿에서 확인하려는 것

기술 검증이 아니라 **운영 판단**을 위한 파일럿입니다. 다음 세 가지를 보십시오.

1. **파서가 얼마나 자주 깨지는가** — 몇 주 돌려 보면 유지보수 부담의 실측치가 나옵니다. 이 수치가 확장 규모(10곳? 30곳?)를 결정합니다
2. **실시간 조회의 체감 속도** — 매 질의마다 기관 사이트를 조회합니다. 느리면 수집 배치 + DB 방식으로 바꿔야 합니다
3. **결과가 0건일 때 이용자가 오해하지 않는가** — "데이터 없음"과 "강좌 없음"을 구분해 표시하도록 만들었는데, 실제로 그렇게 읽히는지 확인해 주십시오

## 8. 기관 추가하는 법

`sources.py`에 클래스를 하나 더 만들고 `server.py`의 `SOURCES`에 등록하면 됩니다.

```python
# sources.py
class PohangSource:
    NAME = "포항"
    def fetch_all(self) -> list[Course]: ...

# server.py
SOURCES = {"경주": _gj, "대구": _dg, "포항": _ph}
```

`Course` 표준 레코드로만 맞춰 주면 검색·정렬·표시는 공통 코드가 처리합니다.

**추가 전 반드시** 공공데이터포털에서 해당 지자체명을 먼저 검색하십시오.
공식 API가 있으면 크롤링하지 마세요 — 대구가 그런 경우였습니다.

## 9. 수집 예절

- 요청 간 0.4초 간격 (`DPS_DELAY`)
- 같은 질의는 10분간 캐시 재사용 (`DPS_CACHE_TTL`)
- 최대 8페이지까지만 수집 (`DPS_MAX_PAGES`)

기관 서버에 부담을 주지 않기 위한 설정입니다. 환경변수로 조정할 수 있지만
**간격을 줄이는 방향으로는 바꾸지 마십시오.** 공공기관 서버는 트래픽 여유가 크지 않습니다.
