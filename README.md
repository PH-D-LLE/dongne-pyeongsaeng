# 동네 평생학습 MCP

우리 동네 평생학습 강좌를 **실시간으로** 찾아 주는 MCP 서버입니다. (v0.7 · 파일럿)

Claude에게 자연어로 물으면 지자체 평생학습포털을 그 자리에서 조회해 답합니다.

```
"경주에 지금 신청할 수 있는 강좌 알려줘"
"저녁 시간대에 들을 수 있는 수업 있어?"
"요즘 뭐 모집해?"
"우리 동네에 배울 수 있는 데 어디 있어?"
```

## 바로 쓰기 — Claude 앱 커넥터 (설치 필요 없음)

서버가 이미 인터넷에 올라가 있습니다. **주소만 등록하면 끝납니다.**

### 1. 커넥터 추가 화면 열기

Claude 앱 → **설정(Settings)** → **커넥터(Connectors)** → **사용자 지정 커넥터 추가**

### 2. 두 칸 입력

| 칸 | 입력할 값 |
|---|---|
| 이름 | `동네 평생학습` |
| 원격 MCP 서버 URL | `https://dongne-pyeongsaeng.onrender.com/mcp` |

**끝에 `/mcp`를 꼭 붙이십시오.** 이걸 빠뜨리는 게 가장 흔한 실수입니다.

「고급 설정」의 OAuth 클라이언트 ID·시크릿 두 칸은 **비워 두세요.** 이 서버는 로그인이 필요 없습니다.

### 3. 추가 → 켜기

**추가** 버튼을 누르고, 커넥터 목록에서 스위치를 켭니다.

### 4. 확인

새 대화에서 물어보세요.

```
경주에 지금 신청할 수 있는 평생학습 강좌 알려줘
```

> **첫 질문은 50초쯤 걸릴 수 있습니다.**
> 무료 요금제라 15분간 아무도 안 쓰면 서버가 잠듭니다. 다시 부르면 깨어나는데 그 시간입니다.
> 한 번 깨우면 이후 질문은 빠르고, 10분간은 같은 조회를 다시 하지 않습니다.
> 첫 시도가 실패하면 한 번 더 물어보세요.

### 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 커넥터 추가가 안 됨 | 주소 끝에 `/mcp`를 붙였는지. `https`인지 |
| 추가는 됐는데 툴이 안 보임 | 커넥터 목록에서 스위치를 켰는지. 새 대화를 시작했는지 |
| 첫 질문이 실패 | 서버가 깨어나는 중입니다. 30초 뒤 다시 물어보세요 |
| 결과가 이상함 | Claude에게 `데이터 소스 점검해줘` 라고 요청 (`check_sources` 툴) |
| 서버가 살아 있나 확인 | 브라우저로 https://dongne-pyeongsaeng.onrender.com 접속. 안내문이 보이면 정상 |

## 무엇을 할 수 있나 — 툴 5개

### `find_courses` — 강좌 찾기

정원·수강료·마감일까지 정리된 강좌를 조건으로 검색합니다. **마감 임박순**으로 보여 줍니다.

| 조건 | 설명 |
|---|---|
| `region` | 전체 / 경주 / 대구 |
| `keyword` | 강좌명·기관명·주제 검색어 |
| `weekday` | "월", "화수", "토일" 처럼 자유 입력 |
| `time_slot` | 오전(6-12) / 오후(12-18) / 저녁(18-23) / 주말 |
| `free_only` | 무료만 (수강료 미확인 건도 포함) |
| `open_only` | 접수 마감 안 지난 것만 (기본 켜짐) |
| `has_seats` | 정원이 남은 것만 |

### `get_course_detail` — 강좌 하나 자세히

`find_courses` 결과의 `id`를 넣으면 정원·접수방법·문의처까지 보여 줍니다.

### `find_institutions` — 평생교육기관 찾기

강좌가 아니라 **"어디서 배울 수 있나"**에 답합니다. 경주 관내 82곳을 유형별로 묶어 보여 줍니다.
유형: 평생학습사랑방·학습포석정 / 주민자치센터 / 도서관 / 대학 평생교육원 / 복지·가족 시설 / 청소년 시설 / 문화 시설 / 지자체 평생학습관 / 민간 학원 / 민간 평생교육원

### `find_notices` — 공지사항 모집 공고

**정형 강좌 목록에 없는 강좌가 여기 실립니다.** 대학·관내 기관·유관기관 프로그램은 사실상 이 경로로만 알려집니다.

강사 채용·시스템 점검 같은 행정 공고는 자동으로 걸러내고, 제목에 적힌 마감일(`~6/30`, `8.20.까지` 등)도 뽑아냅니다.

### `check_sources` — 소스 진단

지금 어느 기관이 살아 있는지, 몇 건이 수집되는지 알려 줍니다. **결과가 이상할 때 제일 먼저 이걸 돌려 보세요.**

## 데이터 출처

| 기관 | 수집 방식 | 상태 |
|---|---|---|
| 경주시 평생학습가족관 | 강좌 목록 화면 실시간 조회 | **동작 중** |
| 경주시 평생학습포털 게시판 | 공지사항·평생학습소식 실시간 조회 | **동작 중** |
| 대구평생학습플랫폼 | [공공데이터포털 공식 오픈API](https://www.data.go.kr/data/15061491/openapi.do) | 인증키 설정 후 동작 |

### 실측으로 확인된 것 (2026년 7월)

- 경주시 평생학습가족관 강좌 **325건** (접수 가능 101건, 전 강좌 유료)
- 관내 평생교육기관 **82곳** — 평생학습사랑방·학습포석정 39%, 주민자치센터 27%
- 게시판 **28건** (모집 15건, 안내 7건)
- **다만 기관별 개설 강좌는 포털에 연계돼 있지 않습니다.** 82곳 중 정형 강좌 정보가 올라온 곳은 가족관 한 곳뿐입니다
- 그런데 게시판에는 대학·유관기관 프로그램 모집 공고가 실제로 올라옵니다. **정보가 없는 것이 아니라 정형화되지 않은 채 흐르고 있었습니다**

이 관찰이 `find_notices` 툴을 만든 이유입니다. 정형 목록만 보면 지역 평생학습 활성도를 실제보다 낮게 평가하게 됩니다.

## 대구 붙이기 (선택)

1. https://www.data.go.kr/data/15061491/openapi.do → **활용신청** (무료·즉시 승인)
2. 마이페이지 → 오픈API → 개발계정 상세보기에서 두 가지 복사
   - **일반 인증키 (Decoding)** ← Encoding 아님
   - **요청 주소** (엔드포인트 URL)
3. Render 대시보드 → 서비스 → **Environment** 탭에 입력 후 저장

```
DAEGU_API_KEY = 일반 인증키 (Decoding)
DAEGU_API_URL = 요청 주소
```

> 요청 주소를 코드에 박아 두지 않은 이유: 데이터셋이 개편되면 주소가 바뀝니다.
> 그때 코드를 고치는 대신 설정만 바꾸면 되도록 했습니다.

## 내 PC에서 직접 돌리기 (개발용)

커넥터로 쓰실 거면 이 장은 필요 없습니다. 코드를 고치거나 기관을 추가할 때 쓰세요.

```
pip install -r requirements.txt
python selftest.py          # 무엇이 되고 안 되는지 항목별 점검
```

`selftest.py`가 이 프로젝트에서 가장 중요한 파일입니다. 파서 로직·검색 필터·게시판 분류를 자동 검증하고, 실제 기관 접속까지 확인합니다. 맨 위에 버전과 `sources.py: 최신` 여부가 표시됩니다.

Claude 데스크톱에 붙이려면 `%APPDATA%\Claude\claude_desktop_config.json` 에 추가합니다.

```json
{
  "mcpServers": {
    "dongne-pyeongsaeng": {
      "command": "python",
      "args": ["C:\\\\실제경로\\\\server.py"]
    }
  }
}
```

역슬래시는 `\\` 두 개씩. Claude 데스크톱을 완전 종료 후 재시작해야 반영됩니다.

## 기관 추가하는 법

`sources.py`에 클래스를 만들고 `server.py`의 `SOURCES`에 등록하면 됩니다. `Course` 표준 레코드로만 맞춰 주면 검색·정렬·표시는 공통 코드가 처리합니다.

**추가 전 반드시 공공데이터포털에서 해당 지자체명을 먼저 검색하십시오.** 공식 API가 있으면 크롤링하지 마세요 — 대구가 그런 경우였습니다. 이걸 모르고 파서를 만들면 유지보수 부담이 0에서 연 단위 인건비로 뜁니다.

정형 강좌 목록이 없는 지자체가 훨씬 많습니다. 그런 곳은 **게시판만 붙여도 실효가 있습니다.** 게시판 파서는 3단 폴백 구조라 마크업이 제각각이어도 대체로 읽어냅니다.

## 수집 예절

- 요청 간 0.4초 간격 (`DPS_DELAY`)
- 같은 질의는 10분간 캐시 재사용 (`DPS_CACHE_TTL`)
- 1회 요청당 100건 수신 (`DPS_ROWS`) — 페이지를 여러 번 넘기지 않기 위해
- 최대 8페이지 (`DPS_MAX_PAGES`)

기관 서버에 부담을 주지 않기 위한 설정입니다. 환경변수로 조정할 수 있지만 **간격을 줄이는 방향으로는 바꾸지 마십시오.** 공공기관 서버는 트래픽 여유가 크지 않습니다.

## 이 파일럿에서 확인하려는 것

기술 검증이 아니라 **운영 판단**을 위한 파일럿입니다.

1. **파서가 얼마나 자주 깨지는가** — 몇 주 돌려 보면 유지보수 부담의 실측치가 나옵니다. 이 수치가 확장 규모(10곳? 30곳?)를 결정합니다
2. **실시간 조회의 체감 속도** — 느리면 수집 배치 + DB 방식으로 바꿔야 합니다
3. **결과가 0건일 때 이용자가 오해하지 않는가** — "데이터 없음"과 "강좌 없음"을 구분해 표시하도록 만들었는데, 실제로 그렇게 읽히는지 확인이 필요합니다

## 알아 두실 것

이 서버는 **주소를 아는 사람은 누구나 접속할 수 있습니다.** 조회 전용이고 공개된 강좌 안내만 다루며 개인정보를 저장하지 않아 파일럿 단계에서는 문제되지 않습니다.

주민에게 정식 공개하는 단계로 간다면 세 가지를 검토하십시오.

1. **접근 제한** — OAuth를 붙이거나, 주소를 공개하지 않고 필요한 사람에게만 전달
2. **기관 서버 부담** — 이용자가 늘면 경주시 서버로 가는 요청도 늘어납니다. 캐시 시간을 늘리거나 하루 한 번 수집해 저장하는 방식으로 바꾸는 편이 낫습니다
3. **출처 기관 협의** — 공개 서비스로 운영한다면 사전에 이야기해 두는 것이 안전합니다

배포·운영 방법은 [DEPLOY.md](DEPLOY.md)를 보세요.
